## Features

- [x] Real-time market data streaming via Interactive Brokers API
- [x] Interactive charting with technical indicators (SMA 50, EMA 10, EMA 20)
- [ ] Market order execution with hotkeys (Shift+O for buy, Shift+P for sell)
- [x] SQLite database for storing historical data, orders, and market scans
- [ ] Support for multiple timeframes (5min, 15min, 1hour)

## Components

- `main.py`: Core trading client and chart interface
- `database.py`: SQLite database management for market data
- Market scanner functionality for stock screening
